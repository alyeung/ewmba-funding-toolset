# 📊 EWMBA Funding Proposal Guide: CLI vs. Browser
### Evening & Weekend MBA Association (EWMBAA) UC Berkeley

Welcome, EWMBA Student Leaders! This workspace is designed to help you draft high-impact, GA-compliant funding proposals using AI. You have two ways to use these tools:

---

## ⚖️ CLI vs. Browser: Which should you use?

| Feature | **Gemini CLI** (Power User) | **ChatGPT/Browser** (Quick Start) |
| :--- | :--- | :--- |
| **Effort** | 5-minute setup (once). | 0 setup. |
| **Capability** | **Autonomous.** Reads guide, researches URLs, and writes files directly to your folder. | **Manual.** You must upload files and copy-paste results. |
| **Accuracy** | High. Cross-references the 590-line policy guide line-by-line. | Medium. May hallucinate rules if the chat gets too long. |
| **Best For** | VPs of Finance or anyone managing multiple proposals. | One-off, simple proposals. |

---

## 🚀 Path A: Gemini CLI (The Automated Way)

Use this path if you want the AI to do the "heavy lifting" of researching your event and writing the actual files for you.

### 1. Installation
The easiest way to set up the CLI is to follow the simplified installer here:
👉 **[EWMBA Gemini Installer](https://github.com/alyeung/mba-gemini-install)**

### 2. The "Power User" Workflow
Open your terminal in this project folder and run:
`gemini "Draft a $2,000 proposal for [Event Name] using the templates in /templates and researching [URL]."`

---

## 🌐 Path B: ChatGPT / Browser (The Manual Way)

Use this path if you want to avoid the terminal and just want a quick draft in your browser.

### 1. Start a New Chat
Go to [ChatGPT](https://chatgpt.com) or [Gemini](https://gemini.google.com).

### 2. Upload the Context
You **MUST** upload these two files from the `/templates` folder so the AI knows the rules:
1. `2026-27 Funding Guide.md` (The Rules)
2. `FUNDING_PROPOSAL_TEMPLATE.md` (The Format)

### 3. The Prompt
Paste this into the chat:
> "I have uploaded the GA Funding Guide and a Template. Help me draft a $2,000 proposal for [Event Name] on [Date]. 
> 
> 1. Use the **Template** format exactly.
> 2. Cross-reference the **Funding Guide** to ensure we don't violate location or class-year rules.
> 3. Here are the event details: [Paste Link or Description].
> 4. Focus the budget on [Catering/Supplies]."

## 📂 Project Structure
*   **`/templates/FUNDING_PROPOSAL_TEMPLATE.md`**: Master template optimized for GA compliance.
*   **`/templates/2026-27 Funding Guide.md`**: The official policy manual.
*   **`/templates/GA Funding - CalLink at UC Berkeley.pdf`**: Schedule and deadlines.

---

## 🛠 Strategic Pro-Tips
*   **The "Plant-Based" Bonus:** Certifying as 100% plant-based unlocks a secondary "sustainability" fund, making your full $2,000 award much more likely.
*   **Student-Led Rationale:** Always emphasize that the event is **student-organized and student-led**. The GA prioritizes peer-to-peer initiatives over school-sponsored programs.
*   **Exclusivity Trap:** Avoid words like "Mandatory" or "Class of 202X." Reframe events as "Community Mixers" to ensure compliance with the GA's Open Access rules.
