## CLI vs. Browser: Selection Guide

| Feature | **Gemini CLI** (Power User) | **ChatGPT/Browser** (Quick Start) |
| :--- | :--- | :--- |
| **Effort** | 5-minute setup (once). | No setup required. |
| **Capability** | **Autonomous.** Reads guide, researches URLs, and writes files directly to your folder. | **Manual.** You must upload files and copy-paste results. |
| **Accuracy** | High. Cross-references the 590-line policy guide line-by-line. | Medium. May hallucinate rules if the chat context becomes too long. |
| **Best For** | VPs of Finance or anyone managing multiple proposals. | One-off, simple proposals. |

## Path A: Gemini CLI (Automated)

Use this path if you want the AI to autonomously research your event and generate the draft files for you.

### 1. Installation
To set up the CLI, follow the installation instructions here:
**[EWMBA Gemini Installer](https://github.com/alyeung/mba-gemini-install)**

### 2. Workflow
Open your terminal in this project folder and run:
`gemini "Draft a $2,000 proposal for [Event Name] using the templates in /templates and researching [URL]."`

---

## Path B: Browser / Web Interface (Manual)

Use this path to generate a quick draft directly in your web browser.

### 1. Start a New Chat
Go to [ChatGPT](https://chatgpt.com) or [Gemini](https://gemini.google.com).

### 2. Upload Context Files
You must upload the following files from the `/templates` folder to provide the AI with the required context:
1. [2026-27 Funding Guide.md](file:///Users/allanyeung/Documents/ewmba-fund/templates/2026-27%20Funding%20Guide.md) (Policy Rules)
2. [FUNDING_PROPOSAL_TEMPLATE.md](file:///Users/allanyeung/Documents/ewmba-fund/templates/FUNDING_PROPOSAL_TEMPLATE.md) (Template Format)

### 3. Prompt
Use the following prompt format:
> "I have uploaded the GA Funding Guide and a Template. Help me draft a $2,000 proposal for [Event Name] on [Date]. 
> 
> 1. Use the **Template** format exactly.
> 2. Cross-reference the **Funding Guide** to ensure we don't violate location or class-year rules.
> 3. Here are the event details: [Paste Link or Description].
> 4. Focus the budget on [Catering/Supplies]."

## Strategic Guidelines
*   **Plant-Based Funding Bonus:** Certifying as 100% plant-based unlocks a secondary sustainability fund, increasing the likelihood of receiving the full $2,000 award.
*   **Student-Led Rationale:** Emphasize that the event is student-organized and student-led. The GA prioritizes peer-to-peer initiatives over school-sponsored programs.
*   **Avoid Exclusivity:** Do not use restrictive language such as "Mandatory" or "Class of 202X." Frame events as "Community Mixers" to satisfy the GA's Open Access requirements.
